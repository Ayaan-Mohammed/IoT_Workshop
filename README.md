# IoT_Workshop
These programs were developed during hands-on IoT training sessions by AB Tech Ville at Geethanjali College of Engineering and Technology, Hyderabad. They demonstrate foundational IoT concepts using ESP8266, including sensor interfacing, automation, and basic real-world applications.

🚀 Projects Included
🔹 Two Blinking LEDs
Demonstrates basic GPIO control
Alternating LED blinking pattern
Helps understand digital output and timing
🚦 Traffic Signal Simulation
Simulates real-world traffic light logic
Uses timed LED sequences (Red, Yellow, Green)
Introduces structured logic and delays
📏 Ultrasonic Sensor
Measures distance using ultrasonic waves
Introduces sensor interfacing
Useful for obstacle detection systems
🛠️ Tech Stack
Arduino IDE
ESP8266 (NodeMCU)
Embedded C (Arduino)
▶️ How to Run
Open any .ino file in Arduino IDE
Select ESP8266 board
Connect your device and choose the correct COM port
Upload the code
